A fix release for **1.3.0**, which is live on the Chrome Web Store. Everything
here was found in real use or by measuring the real extension in a browser.

**Only the extension changes.** The Mnestic Bridge add-on is still **1.3.0** and
needs no update.

## Shortcuts could spoil an unanswered question

The overlays and the panel have always waited until you'd answered. The
keyboard didn't. The question id is in the header *during* a test, and the
shortcuts only checked for an id — so pressing **D** mid-question opened Anki on
that question's own cards: the answer. On a bank where letter keys pick a
choice, choosing D did it by accident.

The small **Anki** button beside the question id had the same flaw: it sat next
to every question of a test, one click from the answer.

Now **no shortcut fires, and no Anki button appears, until the question is
answered and its panel is up.** Before that, every key goes to your qbank
untouched.

## Keys no longer reach the qbank twice

**Paging an image overlay with ← → also changed the question underneath it** —
come out of a five-page First Aid topic and you were several questions along.
The same was true of the letter shortcuts. The handler cancelled the browser's
default action but never stopped the key reaching the qbank's own listener.

A key Mnestic acts on is now claimed outright. With an overlay open, the arrows
never reach the page — including on a single-page overlay, where they used to
slip through.

## The results toolbar stopped bouncing

It had two separate causes, which is why the first fix didn't cure it:

- It re-dodged every control on the page once a second — including ones that
  scroll — so it chased them up and down.
- When the results table re-rendered, it read as empty for a moment; the bar was
  destroyed and rebuilt, lost its position, and slid down from the top again.

It now settles once and stays put, and survives a table that blinks empty.

## Dark mode: text you could not read

Five places, all one mistake — a colour tuned as a *fill* used underneath text.
The dark theme lightens accents, which is right for a bar and fatal for white
text sitting on one. **Save to Missed Qs** measured 2.35:1, **Weak areas** 1.86:1;
readable text needs 4.5. Three of the five were under the line in the light
theme too. All now measure between 4.5 and 7.9.

## Smaller

- **Click a resource's key badge** to show its images. The overlays were
  keyboard-only before.
- Because of that, the popup's **Keyboard shortcuts** toggle now turns *all*
  shortcuts off. Previously F/S/P/O/E/A kept firing with it switched off.
- The popup's **Recheck** is a real button, so screen readers announce it
  correctly.

*Tested: 115 end-to-end checks on the real extension across all three banks —
each new one confirmed to fail on 1.3.0 before it was trusted — plus an audit
that measures every text run's contrast in both themes.*
